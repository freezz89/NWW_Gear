# 燕云装备库

《燕云十六声》装备验货与调律助手：把你的装备录进来，它告诉你每一件该**留 / 转律 / 扔**，并列出整套还缺哪些词条。

> 非官方玩家自制工具，与游戏官方无关。公式和数值来自玩家实测，版本更新后可能变化，仅供参考。

## 怎么用

- **直接用**：下载 `index.html`，双击用浏览器打开就行，不用安装、不用联网（字体和截图识别需要网络，没有也能用）。
- **放到网上**：把仓库开启 GitHub Pages（Settings → Pages → 选 main 分支根目录），访问 `https://<你的用户名>.github.io/<仓库名>/`。

页面里点「? 说明」有 5 步上手教程。

## 它能做什么

- 验货：按流派的满配词条，判定每件装备是 完美件 / 完美[转] / 合格件 / 过渡件 / 扔
- 全套账本：精准、势、会意、劲等词条整套还差几条，转律时该选哪个系的方向
- 参考毕业面板、面板对账、装备库管理、官方面板一键导入、截图识别录入

## 数据和隐私

- 你录的角色、装备**只存在你自己浏览器的 localStorage 里**，不会上传到任何服务器。
- 换设备、换浏览器、清缓存之前，请在页面顶部点「导出备份」，到新地方点「导入备份」。
- 仓库里不含任何个人数据；游戏官方图标也没有内置。
